HTML TAG

  1. <strong>블라블라</stong> = 굵게
  2. <u>블라블라</u> = 밑줄
  3. <h1>블라블라</h1> = 제목, 줄바꿈 (1~6 까지 있음)
  4. <br> = 줄 바꿈
  5. <p></p> = 단락 나누기
  6. <img src=".jpg"width="450"> = 원하는 크기로 이미지 넣기
  7. <li></li> = 목차
  8. <ol></ol> = 목차 숫자로 바꾸기
  9. <title></title> = 링크 제목
  10. <meta charest="utf8"> = utf8 브라우저로 항상 열게해라.(한국어지원)
  11. <head></head> = 타이틀 부분 묶기
  12. <body></body> = 본문 묶기
  13. <html></html> = 전체 묶기
  14. <!DOCTYPE html> = 작성된 코딩
  15. <a></a> = 링크
  16. href="링크주소" = 링크 삽입
  17. title="링크 툴팁명" = 링크 툴팁 설명
